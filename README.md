# Numi-OT.01

Numi-OT.01 is the conversational AI model developed for the Chat experience
of Numination.

## Architecture

The project contains its own model architecture, tokenizer, training,
evaluation and inference systems.

## Development

Development is performed through GitHub with automated validation through
GitHub Actions.

## Base Model

The initial foundation is Qwen3-30B-A3B-Base.

The architecture and behavior of Numi-OT.01 will be progressively modified
and extended for Numination.

## Structure

- `architecture/` — model architecture
- `tokenizer/` — tokenizer
- `training/` — training system
- `datasets/` — datasets
- `evaluation/` — evaluation
- `inference/` — inference
- `server/` — serving API
- `configs/` — configurations
- `scripts/` — automation
- `model/` — model metadata
- `tests/` — automated tests
