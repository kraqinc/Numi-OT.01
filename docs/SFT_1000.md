3. Ciberseguridad  
4. Código  
5. Lenguaje natural / NLP

## Generar el JSONL

```bash
python scripts/build_sft_1000.py
# → datasets/2026/numi_sft_1000.jsonl
```

## Entrenar (Colab Pro / GPU buena)

```bash
python scripts/build_sft_1000.py
PYTHONPATH=. python scripts/training/train_base_lora.py --config configs/training/lora_frontier.yaml
```
